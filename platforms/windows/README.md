# Version Windows

La version Windows cible **Windows 10/11 avec Lively Wallpaper** et conserve les deux compositions :

- écran principal paysage 2K/4K à gauche ;
- écran décoratif vertical prioritaire à droite ;
- mode par écran recommandé, avec mode étendu disponible.

Depuis la racine du projet, utiliser :

- `Apercu-Windows.cmd` pour l’aperçu local ;
- `Verifier-Windows.cmd` pour les tests ;
- `Construire-Lively-Windows.cmd` pour créer `dist\windows\Liquide-Wallpaper-Lively.zip`.

Les fichiers `LivelyInfo.json` et `LivelyProperties.json` de ce dossier sont les métadonnées canoniques de la distribution Windows. Le moteur HTML/WebGL reste commun aux deux plateformes.
